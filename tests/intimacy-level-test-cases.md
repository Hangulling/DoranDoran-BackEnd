# 친밀도 레벨 유지 테스트 케이스

## 개요
격식체 챗봇(coworker, boss, senior)이 낮은 친밀도에서 사용자의 친근한 말투에 영향받지 않고 일관된 레벨을 유지하는지 검증하는 테스트 케이스입니다.

## 테스트 환경 설정
- 친밀도 레벨: 1 (격식체) 또는 2 (표준 존댓말)
- 대상 봇: coworker-bot, boss-bot, senior-bot
- 테스트 시나리오: 사용자가 친근한 말투로 대화를 시도할 때 봇이 격식체를 유지하는지 확인

## Coworker Bot - Level 1 (격식체)

### Test Case 1: 업무 과중 상황
**User Input:**
```
이번 업무 너무 많아서 힘들어요 ㅠㅠ
```

**Expected Response:**
```
업무량이 과중하신 것 같습니다. 팀장님께 일정 조율을 요청해보시는 것이 좋겠습니다.
```

**Forbidden Elements:**
- ❌ "아 진짜요?", "ㅠㅠ", "힘들겠다"
- ❌ 반말: "~해", "~야", "~지?"
- ❌ 구어체 감탄사: "대박", "헐", "에휴"
- ❌ 이모티콘: "ㅠㅠ", "ㅋㅋ", "ㅎㅎ"

### Test Case 2: 점심 약속
**User Input:**
```
점심 같이 먹을래요?
```

**Expected Response:**
```
좋습니다. 몇 시에 어디서 만나시겠습니까?
```

**Forbidden Elements:**
- ❌ "좋아요~", "ㅎㅎ", "언제 갈까요?"
- ❌ 친근한 표현: "~해요~", "~지요?"

### Test Case 3: 프로젝트 진행 상황
**User Input:**
```
프로젝트 진행 상황 어때?
```

**Expected Response:**
```
프로젝트는 계획대로 진행되고 있습니다. 세부 사항을 보고드리겠습니다.
```

**Forbidden Elements:**
- ❌ "오 잘 되고 있어요", "ㅋㅋ", 반말
- ❌ 구어체: "어때?", "괜찮아?"

## Boss Bot - Level 1 (공식 보고체)

### Test Case 1: 보고서 완성
**User Input:**
```
보고서 완성했어요!
```

**Expected Response:**
```
보고서 제출 감사합니다. 확인 후 피드백 드리겠습니다.
```

**Forbidden Elements:**
- ❌ "오~ 잘했네요!", "고생했어요 ㅎㅎ"
- ❌ 친근한 표현: "~네요!", "~어요!"
- ❌ 이모티콘: "ㅎㅎ", "ㅋㅋ"

### Test Case 2: 업무 어려움
**User Input:**
```
이 부분 어떻게 해야 할지 모르겠어요 ㅠㅠ
```

**Expected Response:**
```
해당 부분에 대해 함께 검토해보겠습니다. 회의 일정을 잡아주시겠습니까?
```

**Forbidden Elements:**
- ❌ "음... 그건 좀", "ㅠㅠ", 구어체
- ❌ "어떻게 해야 할지" → "어떻게 해야 할지" (구어체)
- ❌ 이모티콘: "ㅠㅠ"

### Test Case 3: 야근 상황
**User Input:**
```
오늘 야근해야 할 것 같아요 ㅜㅜ
```

**Expected Response:**
```
야근이 필요하시군요. 건강에 유의하시기 바랍니다.
```

**Forbidden Elements:**
- ❌ "아 진짜요?", "ㅜㅜ", "힘들겠다"
- ❌ 구어체: "~것 같아요", "~어요"
- ❌ 이모티콘: "ㅜㅜ"

## 테스트 실행 방법

### 1. 환경 설정
```bash
# 친밀도 레벨 설정 (DB 또는 설정 파일)
intimacy_level = 1  # 또는 2
concept = "COWORKER" | "BOSS" | "SENIOR"
```

### 2. 테스트 실행
각 테스트 케이스를 순차적으로 실행하고 응답을 검증합니다.

### 3. 검증 기준
- ✅ **필수 표현 사용**: 격식체 어미(~습니다, ~어요) 사용
- ✅ **금지 표현 회피**: 이모티콘, 구어체 감탄사, 반말 사용 안 함
- ✅ **일관성 유지**: 대화 전체에서 동일한 레벨 유지
- ✅ **컨셉 적합성**: 직장/학교 상황에 맞는 적절한 표현

### 4. 실패 시 확인사항
- PromptService의 `appendFormalSpeechConstraints()` 메서드 동작 확인
- ConversationAgent의 `injectIntimacyReminder()` 동작 확인
- 로그에서 친밀도 레벨과 컨셉 정보 확인

## 중의적 표현 처리 테스트 케이스

### Test Case: 중의적 질문/진술
**User Input:**
```
오늘까지 뭐 확인할 거 있어
```

**Expected Responses by Level:**

#### Level 1 (격식체)
```
확인하실 사항이 있으신지요? 구체적으로 어떤 부분을 확인하시겠습니까?
```

#### Level 2 (표준 존댓말)
```
확인할 일이 있으신가요? 어떤 것들을 확인하시려고 하시는지요?
```

#### Level 3 (친근한 말투)
```
뭐 확인할 거 있어? 어떤 거?
```

**Forbidden Elements:**
- ❌ Level 1에서: "뭐 확인할 거 있어?", "어떤 거?"
- ❌ Level 2에서: "뭐 확인할 거야?", 반말
- ❌ Level 3에서: "확인하실 사항이 있으신지요?", 격식체

### Test Case: 감정 표현 중의성
**User Input:**
```
그 사람이 좋아
```

**Expected Responses by Level:**

#### Level 1 (격식체)
```
해당 분을 좋아하시는 건가요, 아니면 그분이 좋은 분이라는 말씀이신가요?
```

#### Level 2 (표준 존댓말)
```
그 사람을 좋아하시는 건가요? 아니면 그분이 좋은 분이라는 뜻인가요?
```

#### Level 3 (친근한 말투)
```
그 사람 좋아해? 아니면 그 사람이 좋다는 거야?
```

### Test Case: 요청/상태 중의성
**User Input:**
```
문 열어줘
```

**Expected Responses by Level:**

#### Level 1 (격식체)
```
문을 열어드릴까요, 아니면 문이 열렸다는 말씀이신가요?
```

#### Level 2 (표준 존댓말)
```
문을 열어드릴까요? 아니면 문이 열렸다는 뜻인가요?
```

#### Level 3 (친근한 말투)
```
문 열어줄까? 아니면 문 열렸다는 거야?
```

## 예상 개선 효과

### Before (문제 상황)
```
User: "이번 업무 너무 많아서 힘들어요 ㅠㅠ"
Bot: "아 진짜요? 너무 힘들겠다 ㅠㅠ 팀원들하고 잘 조율해봐야 할 것 같아"
```

### After (개선 후)
```
User: "이번 업무 너무 많아서 힘들어요 ㅠㅠ"
Bot: "업무량이 과중하신 것 같습니다. 팀장님께 일정 조율을 요청해보시는 것이 좋겠습니다."
```

### 핵심 개선점
1. **격식체 유지**: ~습니다 어미 일관 사용
2. **이모티콘 제거**: ㅠㅠ, ㅋㅋ 등 사용 안 함
3. **구어체 회피**: "아 진짜요?", "힘들겠다" 등 구어체 사용 안 함
4. **전문적 톤**: 업무 상황에 맞는 정중하고 전문적인 표현
