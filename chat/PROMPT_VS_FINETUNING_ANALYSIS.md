# 말투/서술어 전문화: 프롬프트 강화 vs 파인튜닝 비교 분석

## 📊 현재 상황 분석

### 현재 프롬프트 수준

코드를 분석한 결과, **이미 매우 상세한 프롬프트**를 사용하고 있습니다:

1. **컨셉별 세부 지침** (FRIEND, COWORKER, BOSS, SENIOR, HONEY)
2. **친밀도 레벨별 구체적 규칙** (Level 1-3)
3. **사용 가능/금지 표현 목록**
4. **예시 포함** (잘못된 예시 vs 올바른 예시)
5. **프롬프트 길이**: 2000+ 줄

예시:
```java
// FRIEND Level 3의 경우
- 반말 종결어미: ~해, ~야, ~지?, ~잖아
- 줄임말: ㅇㅇ, ㄱㄱ, ㅇㅈ, ㄴㄴ 허용
- 속어/신조어: "개좋아", "레알", "완전" 허용
- 절대 사용 금지: 존댓말 전부 금지
```

## 🤔 프롬프트 강화 vs 파인튜닝 비교

### 시나리오별 권장사항

#### ✅ **프롬프트 강화가 더 나은 경우**

**1. 규칙 기반 말투 제어**
- ✅ 현재 상황에 해당
- 컨셉별/레벨별 명확한 규칙이 있는 경우
- 예: "FRIEND Level 3은 반말만 사용", "COWORKER는 존댓말 유지"

**2. 예시를 통한 학습 가능**
- ✅ 현재 프롬프트에 예시 포함
- Few-shot learning으로 충분히 학습 가능
- 예: "❌ 좋네요~ → ✅ 좋아~"

**3. 빠른 반복 개선 필요**
- ✅ 프롬프트 수정은 즉시 적용 가능
- A/B 테스트 용이
- 재배포 불필요 (템플릿 분리 시)

**4. 비용 효율성**
- ✅ API 호출 비용만 발생
- 파인튜닝 학습 비용 없음
- 인프라 구축 불필요

**5. 일관성 문제가 규칙 위반인 경우**
- ✅ 프롬프트에 더 명확한 규칙 추가
- 예: "⚠️⚠️⚠️ 절대 사용 금지" 같은 강조

---

#### ⚠️ **파인튜닝이 더 나은 경우**

**1. 매우 세밀한 스타일 차이**
- 예: "서울 사투리 vs 부산 사투리"
- 예: "20대 말투 vs 40대 말투"
- 예: "특정 직업군의 전문 용어 사용 패턴"

**2. 프롬프트로는 한계가 명확한 경우**
- 프롬프트를 5000줄 이상 늘려도 일관성 문제
- 규칙이 너무 복잡해서 프롬프트로 표현 불가
- 모델이 규칙을 무시하는 경우가 빈번

**3. 대량의 도메인 특화 데이터 보유**
- 수만~수십만 개의 대화 로그
- 명확한 라벨링된 데이터
- 지속적인 데이터 수집 가능

**4. 비용/지연시간 최적화 필요**
- API 호출 비용이 과도한 경우
- 지연시간이 중요한 경우
- 자체 인프라 운영 가능

## 💡 구체적 권장사항

### 현재 상황 기준: **프롬프트 강화 우선**

#### 이유

1. **이미 상세한 프롬프트 사용 중**
   - 2000+ 줄의 세부 지침
   - 컨셉별/레벨별 명확한 규칙
   - 예시 포함

2. **규칙 기반 제어가 가능**
   - 말투(존댓말/반말)는 명확한 규칙
   - 서술어 선택도 프롬프트로 제어 가능
   - 단어 사용도 금지/허용 목록으로 관리 가능

3. **GPT-4.0 mini의 강점 활용**
   - Few-shot learning 능력 우수
   - 긴 프롬프트 처리 가능
   - 규칙 준수 능력 좋음

---

### 프롬프트 강화 전략

#### 1. 구조화된 예시 추가 (Few-shot Learning 강화)

**현재:**
```java
prompt.append("**절대 사용 금지: 존댓말 전부 금지**\n");
```

**개선:**
```java
prompt.append("""
    **[Few-shot 예시 - 반드시 이 패턴을 따르세요]**
    
    사용자: "오늘 날씨가 좋네요"
    ❌ 잘못된 응답: "네, 날씨가 정말 좋네요~"
    ✅ 올바른 응답: "응, 날씨 진짜 좋다~"
    
    사용자: "뭐 먹고 싶으세요?"
    ❌ 잘못된 응답: "저는 파스타를 먹고 싶어요"
    ✅ 올바른 응답: "나는 파스타 먹고 싶어"
    
    사용자: "어디 가세요?"
    ❌ 잘못된 응답: "저는 카페에 가요"
    ✅ 올바른 응답: "나는 카페 가"
    """);
```

#### 2. 서술어 사전 정의

**개선 방안:**
```java
// 서술어 매핑 테이블
Map<String, String> verbMapping = Map.of(
    "먹다", Map.of(
        "FRIEND_L1", "먹다",
        "FRIEND_L3", "먹다",
        "COWORKER_L1", "식사하다",
        "COWORKER_L3", "드시다"
    ),
    "보다", Map.of(
        "FRIEND_L1", "보다",
        "FRIEND_L3", "보다",
        "COWORKER_L1", "확인하다",
        "COWORKER_L3", "보시다"
    )
);

// 프롬프트에 주입
prompt.append("""
    **[서술어 사용 규칙]**
    - "먹다" → FRIEND: "먹다", COWORKER: "식사하다" 또는 "드시다"
    - "보다" → FRIEND: "보다", COWORKER: "확인하다" 또는 "보시다"
    - 반드시 위 규칙을 따르세요.
    """);
```

#### 3. 단어 사용 빈도 제어

**개선 방안:**
```java
prompt.append("""
    **[단어 사용 빈도 규칙]**
    - 이모티콘(ㅋㅋ, ㅎㅎ): 문장당 최대 1-2개
    - 줄임말(ㅇㅇ, ㄱㄱ): 문장당 최대 1개
    - 감탄사(헐, 대박): 문장당 최대 1개
    - 말 늘이기(~요~, ~해~): 문장당 최대 1개
    """);
```

#### 4. 문맥별 예외 규칙

**개선 방안:**
```java
prompt.append("""
    **[문맥별 예외 규칙]**
    - 질문에 답할 때: 반말 유지하되 "~지?" 사용
    - 제안할 때: "~할래?" 또는 "~하자" 사용
    - 거절할 때: "~안 돼" 또는 "~싫어" 사용
    - 동의할 때: "~맞아" 또는 "~그렇지" 사용
    """);
```

### 프롬프트 강화의 한계와 대안

#### 프롬프트로 해결 어려운 경우

**1. 매우 자연스러운 대화 흐름**
- 프롬프트: 규칙 기반 → 어색할 수 있음
- 파인튜닝: 실제 대화 데이터 학습 → 자연스러움

**2. 미묘한 뉘앙스**
- 프롬프트: "부드러운 반말" 같은 추상적 표현
- 파인튜닝: 실제 예시 학습 → 뉘앙스 포착

**3. 일관성 문제가 지속되는 경우**
- 프롬프트를 5000줄 이상 늘려도 개선 안 됨
- 모델이 규칙을 무시하는 빈도 높음

---

### 하이브리드 접근법 (권장)

#### Phase 1: 프롬프트 강화 (즉시)

1. **Few-shot 예시 추가**
   - 각 컨셉/레벨별 10-20개 예시
   - 잘못된 예시 vs 올바른 예시

2. **서술어/단어 사전 정의**
   - 컨셉별/레벨별 허용 단어 목록
   - 금지 단어 목록

3. **평가 파이프라인 구축**
   - 프롬프트 변경 전후 비교
   - 일관성 측정

#### Phase 2: 데이터 수집 (병행)

1. **대화 로그 수집**
   - Agent 실행 로그 저장
   - 사용자 피드백 수집

2. **라벨링 작업**
   - 이상적인 응답 라벨링
   - 문제가 있는 응답 라벨링

3. **데이터셋 구축**
   - 1000-5000개 이상의 QA 페어
   - 컨셉별/레벨별 균형

#### Phase 3: 파인튜닝 검토 (선택적)

**조건:**
- 프롬프트 강화로도 일관성 문제 지속
- 5000개 이상의 고품질 데이터 확보
- 비용/지연시간 최적화 필요

**방법:**
- 오픈소스 모델 도입 (Llama 3.1 8B 등)
- LoRA 파인튜닝
- 특정 Agent만 선별 파인튜닝 (예: ConversationAgent만)

## 📈 구체적 개선 예시

### 예시 1: FRIEND Level 3 말투 전문화

**현재 프롬프트:**
```java
prompt.append("반말 종결어미: ~해, ~야, ~지?, ~잖아\n");
prompt.append("줄임말: ㅇㅇ, ㄱㄱ, ㅇㅈ, ㄴㄴ 허용\n");
```

**강화된 프롬프트:**
```java
prompt.append("""
    **[FRIEND Level 3 말투 전문화 - 실제 친구처럼]**
    
    **반드시 사용할 표현:**
    - 종결어미: ~해, ~야, ~지?, ~잖아, ~할래?
    - 줄임말: 문장에 자연스럽게 섞기 (예: "ㅇㅇ 그렇지", "ㄱㄱ 같이 가자")
    - 감탄사: "헐", "대박", "진짜?" (자연스럽게)
    - 말 늘이기: "좋아아~", "알겠써~" (가끔 사용)
    
    **Few-shot 예시:**
    사용자: "오늘 뭐 할 거야?"
    ✅ "아직 안 정했는데, 뭐 하고 싶은 거 있어?"
    ✅ "ㅇㅇ 아직 안 정했는데, 뭐 하고 싶은 거 있어?"
    
    사용자: "나 오늘 피곤해"
    ✅ "아 힘들겠다ㅠㅠ 푹 쉬어"
    ✅ "헐 힘들겠다ㅠㅠ 푹 쉬어"
    
    사용자: "내일 만날까?"
    ✅ "응 좋아! 몇 시에?"
    ✅ "ㅇㅇ 좋아! 몇 시에?"
    
    **절대 사용 금지:**
    ❌ "네, 좋은 생각이네요~" (존댓말)
    ❌ "내일 만나시겠어요?" (존댓말)
    ❌ "괜찮으시겠어요?" (존댓말)
    """);
```

### 예시 2: 서술어 선택 규칙

prompt.append("""

    **예시:**

    COWORKER Level 1: "식사하셨습니까?" ✅
    COWORKER Level 3: "밥 드셨어요?" ✅
    """);
