# 20260303_푸시알림히스토리_페이로드변경

> 2026-03-03 적용: FCM 페이로드 표준화 + 안읽음 푸시 API 신규 도입

---

## 1. 변경 사항 요약

| 구분 | 내용 |
|------|------|
| **FCM 페이로드** | `notification.title` 고정 "도란도란", `data` 필드 순서 및 기본값 표준화 |
| **안읽음 푸시** | `unread_push_logs` 테이블 신규, 조회/읽음 처리 API 추가 |
| **푸시 발송 시점** | `sendToUser`, `sendByTopic`, `sendChatroomCreatePush` 성공 시 `unread_push_logs` 자동 기록 |

---

## 2. 공통 사항

### 2.1 인증

- **클라이언트 요청**: `Authorization: Bearer {accessToken}` (JWT)
- **Gateway**: JWT 검증 후 `X-User-Id` 헤더를 백엔드로 전달
- 알림/딥링크 API는 `X-User-Id`(UUID) 필수

### 2.2 Content-Type

- 요청: `application/json` (Body 있는 경우)
- 응답: `application/json`

## 3. FCM 페이로드 변경 (2026-03-03)

### 3.1 적용 전 vs 적용 후

#### (1) `sendToUser` — 기존 채팅방 메시지 푸시

| 항목 | 적용 전 | 적용 후 |
|------|---------|---------|
| notification.title | 요청값 (예: "직장 동료") | 요청값 또는 **기본값 "도란도란"** |
| notification.body | 요청값 | 요청값 또는 **기본값 "새로운 메시지가 도착했습니다."** |
| data | deeplink, universalLink, chatroomId, messageId, startMessage, sentAt | 동일 (변경 없음) |

#### (2) `sendByTopic` / `sendChatroomCreatePush` — 채팅방 생성용 푸시

| 항목 | 적용 전 | 적용 후 |
|------|---------|---------|
| notification.title | 컨셉명(예: "직장 동료") | **"도란도란" (고정)** |
| notification.body | greeting 문구 | greeting 문구 (동일) |
| data 필드 순서 | deeplink, chatbotId, topic, concept, startMessage, sentAt | **concept, chatbotId, topic, startMessage, deeplink, sentAt** |

### 3.2 data 페이로드 상세

**기존 채팅방 진입용** (sendToUser / 2.2 send 사용 시)

```json
{
  "deeplink": "dorandoran://chat?roomId=xxx&messageId=yyy",
  "universalLink": "https://www.doran-chat.com/chat?roomId=xxx&messageId=yyy",
  "chatroomId": "uuid",
  "messageId": "uuid",
  "startMessage": "오늘 날씨 어때?",
  "sentAt": "2026-03-03T09:00:00+09:00"
}
```

**채팅방 생성용** (sendByTopic, sendChatroomCreatePush, test-chatroom-push 사용 시)

```json
{
  "concept": "coworker",
  "chatbotId": "uuid",
  "topic": "일상",
  "startMessage": "오늘 날씨 어때?",
  "deeplink": "dorandoran://chatroom/create?chatbotId=xxx&topic=일상&concept=coworker",
  "sentAt": "2026-03-03T09:00:00+09:00"
}
```

## 4. 푸시 알림 API (User 서비스)

Base path: `/api/notifications`

### 4.1 FCM 토큰 등록

```
POST /api/notifications/register
```

| 구분 | 내용 |
|------|------|
| 헤더 | `X-User-Id`: 사용자 UUID (Gateway가 JWT에서 주입) |
| Body | `{ "token": "fcm_token_string", "platform": "android" }` 또는 `"ios"` |

**응답**

- `200 OK`: 성공 (Body 없음)
- `400 Bad Request`: 잘못된 userId 또는 등록 실패

---

### 4.2 푸시 발송 (내부용)

```
POST /api/notifications/send
```

| 구분 | 내용 |
|------|------|
| Body | `userId`(UUID), `title`, `body`, `chatroomId`(UUID, 선택), `messageId`(UUID, 선택) |

**동작**

- 해당 사용자 FCM 토큰으로 푸시 전송
- data 페이로드: `deeplink`, `universalLink`, `chatroomId`, `messageId`, `startMessage`, `sentAt`
- title/body 미입력 시 기본값 사용
- 푸시 발송 성공 시 `unread_push_logs`에 기록

**응답**

- `200 OK`: 성공 (Body 없음)
- `400 Bad Request`: 실패

---

### 4.3 안읽음 푸시 조회 (2026-03 신규)

```
GET /api/notifications/unread?page=0&size=20
```

| 구분 | 내용 |
|------|------|
| 헤더 | `Authorization: Bearer {accessToken}`, `X-User-Id` (Gateway 주입) |
| 쿼리 | `page`(기본 0), `size`(기본 20) |

**응답** (200 OK)

```json
{
  "success": true,
  "data": {
    "content": [
      {
        "id": 1,
        "pushType": "CHATROOM_CREATE",
        "chatbotId": "uuid",
        "chatroomId": null,
        "messageId": null,
        "concept": "coworker",
        "topic": "일상",
        "startMessage": "오늘 날씨 어때?",
        "title": "도란도란",
        "body": "오늘 날씨 어때?",
        "sentAt": "2026-03-03T09:00:00+09:00"
      }
    ],
    "totalElements": 3,
    "totalPages": 1,
    "number": 0,
    "size": 20,
    "unreadCount": 3
  }
}
```

| 필드 | 타입 | 설명 |
|------|------|------|
| pushType | string | CHATROOM_CREATE \| NEW_MESSAGE |
| chatbotId | UUID | 챗봇 ID (채팅방 생성용) |
| chatroomId | UUID | 채팅방 ID (기존 채팅방 메시지용) |
| messageId | UUID | 메시지 ID (기존 채팅방 메시지용) |
| concept | string | 컨셉 (coworker, friend 등) |
| topic | string | 주제 |
| startMessage | string | 그리팅에 사용할 문구 |
| title, body | string | 푸시 제목/본문 |
| sentAt | ISO-8601 | 발송 시각 (KST) |
| unreadCount | number | 전체 안읽음 건수 |

---

### 4.4 안읽음 푸시 읽음 처리 (2026-03 신규)

**일괄 읽음 처리**

```
POST /api/notifications/unread/mark-read
```

| 구분 | 내용 |
|------|------|
| Body | `{ "ids": [1, 2, 3] }` — 지정 id만 읽음 처리. `ids`가 null/빈 배열이면 **전체** 읽음 처리 |

**단건 읽음 처리**

```
POST /api/notifications/unread/{id}/mark-read
```

**응답**

- `200 OK`: 성공 (`"읽음 처리되었습니다."`)
- `404 Not Found`: 해당 id가 없거나 본인 소유가 아님 (단건만)

---

### 4.5 푸시 발송 로그 조회

```
GET /api/notifications/logs?userId={uuid}&page=0&size=20
```

| 쿼리 | 타입 | 필수 | 기본값 | 설명 |
|------|------|------|--------|------|
| userId | UUID | O | - | 사용자 ID |
| page | int | X | 0 | 페이지 번호 |
| size | int | X | 20 | 페이지 크기 |

**응답** (200 OK): 페이지 형식. `content` 배열 + 페이지 메타.

---

### 4.6 주제 기반 푸시 발송 (관리자/스케줄러용)

```
POST /api/notifications/send-by-topic
```

| 구분 | 내용 |
|------|------|
| Body | `userId`(UUID, 필수), `chatbotId`(UUID, 필수), `topic`(선택), `concept`(선택, 기본 "FRIEND"), `intimacyLevel`(선택, 기본 2, 1~3) |

**동작**

- 주제·컨셉에 맞는 제목/본문 생성 후 해당 사용자에게 FCM 1회 발송
- notification.title: "도란도란" (고정)
- data: concept, chatbotId, topic, startMessage, deeplink, sentAt
- 발송 성공 시 `unread_push_logs`에 기록

**응답**

- `200 OK`: `"주제 기반 푸시가 전송되었습니다."`
- `400 Bad Request`: userId/chatbotId 누락, FCM 토큰 없음 등

## 5. 딥링크 API (참고)

### 5.1 채팅방 생성/조회 (Chat 서비스)

```
GET /api/deeplink/chatroom/create?chatbotId={uuid}&topic={주제}&concept=FRIEND&intimacyLevel=2
```

- `X-User-Id` 필수
- 쿼리: `chatbotId`(필수), `topic`(선택), `concept`(선택, 기본 "FRIEND"), `intimacyLevel`(선택, 기본 2)

### 5.2 안읽음 푸시 클릭 플로우

1. 앱이 data에서 `chatbotId`, `topic`, `concept`, `startMessage` 추출
2. `GET /api/deeplink/chatroom/create?chatbotId=...&topic=...&concept=...` 호출
3. 채팅방 생성 후 `POST .../greeting/start`에 `startMessage` 전달하여 그리팅 생성
4. `POST /api/notifications/unread/{id}/mark-read`로 읽음 처리

## 7. DB 스키마 (unread_push_logs)

```sql
CREATE TABLE user_schema.unread_push_logs (
  id BIGSERIAL PRIMARY KEY,
  user_id UUID NOT NULL,
  push_type VARCHAR(20) NOT NULL,  -- 'CHATROOM_CREATE' | 'NEW_MESSAGE'
  chatbot_id UUID,
  chatroom_id UUID,
  message_id UUID,
  concept VARCHAR(20),
  topic VARCHAR(255),
  start_message TEXT,
  title VARCHAR(255),
  body TEXT,
  sent_at TIMESTAMPTZ NOT NULL,
  created_at TIMESTAMPTZ DEFAULT NOW(),
  read_at TIMESTAMPTZ
);
CREATE INDEX idx_unread_push_user_read ON user_schema.unread_push_logs(user_id, read_at);
```

- Flyway: `V12__add_unread_push_logs.sql`
